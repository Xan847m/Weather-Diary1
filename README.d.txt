# Weather Diary

## Автор
Хан Константин

## Описание
Приложение для записи и просмотра погодных условий. Позволяет добавлять записи с датой, температурой, описанием и наличием/отсутствием осадков. Включает функции фильтрации по дате и температуре, сохранения и загрузки данных.

## Как запустить
1. Установите Python 3.
2. Скачайте или склонируйте репозиторий.
3. Запустите команду: `python weather_diary.py`.
4. Введите данные и пользуйтесь интерфейсом.

## Примеры
- Добавление записи за 2024-04-12 с температурой +15°C и описанием "солнечно".
- Фильтр по дате: "2024-04-12".
- Фильтр по температуре: выше 10°C.
